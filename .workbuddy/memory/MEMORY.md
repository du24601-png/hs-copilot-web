# HS Copilot 项目长期笔记

## 数据库事实（2026-09-03 核实）

- `hs_copilot.db` 共 12,032 条 10 位编码。唯一注释类字段是 `hs_code.note`（5,637 条非空）。
- **该 note 不是本国子目注释，也不是品目注释**，实为税则表"备注"栏（10 位级的描述性限定语）。
- 与官方《本国子目注释表》逐条比对后的定性：①部分为官方注释的**删减摘抄**，且常丢掉最有归类价值的定性（22060010 黄酒丢了"发酵酒"）②部分性质完全不同（10061021 官方讲粒长，库内只有"配额内/配额外"）③官方有注而库内为空（02089010、25010020、48021010、39269010、39076110）。
- **全库缺失的知识层**：归类总规则六条、类注、章注、品目注释、子目注释、本国子目注释。
- **补录数据源（2026-09-03 已全部实测下载）**：
  - **首选**：《中华人民共和国进出口税则》(2026) 正本 PDF，1492 页 70MB，`https://m.mof.gov.cn/czxw/202512/P020251231607833453633.pdf`（国务院关税税则委员会编）。**一份文件含归类总规则、类注、章注（97 章）、子目注释、本国子目注释、税目税率表**，按章分散排布（章标题 → 注释：→ 子目注释 → 本国子目注释 → 税目表）。已存 `tools/raw/shuize2026.pdf`。
  - 次选：各省转载的《本国子目注释表》全表 PDF（如 `hunan.gov.cn` 2024/12 附件），2025 版 198 条。已存 `tools/raw/hunan_bgzmzs_2024.pdf`。
  - 补充：财政部税委会公告年度《本国子目注释**调整表**》（只列变动，2026 版仅 5 条），`https://m.mof.gov.cn/zcfb/202512/P020251229510522003597.pdf`。**注意"调整表"≠"全表"**，别拿错。
- **条数口径（易混）**：本国子目注释 2026 版 = **201 条注释 / 覆盖 240 个税则号列**（一条注释常并列多个号列，如长粒米一条挂 5 个）。2025 版 = 198 条 / 233 个号列。提到"240 条"通常指号列数。
- PDF 解析坑：财政部 PDF 用 SimHei 字体且 FontDescriptor 同时含 FontFile2/FontFile3，**pypdf 会报 "More than one /FontFile found"**；改用 PyMuPDF（`import pymupdf`）可正常解析。

## 项目约定

- 服务启动：`node server.js` → http://127.0.0.1:7100/ ，Node 原生 http，零依赖。
- 单元测试需 Node 24（`--test-isolation=none` 在 Node 22 上名为 `--experimental-test-isolation`）。
- 数据库为唯一数字真相：编码、税率、申报要素只能出自 DB，LLM 输出必须命中候选集。
