## 可重复导入

安装 `tools/requirements.txt` 中的Python依赖后，在项目目录执行：

```powershell
# 只读预检，不修改源数据库及其WAL/SHM
python tools/import_ruling_knowledge.py --xlsx tools/data/rulings-104.xlsx --db hs_copilot.db --dry-run

# 正式导入：先备份，再事务内替换本来源
python tools/import_ruling_knowledge.py --xlsx tools/data/rulings-104.xlsx --db hs_copilot.db

# 离线安全测试（不调用模型）
python -m unittest test.test_legal_knowledge_import test.test_ruling_knowledge_import -v
npm test
```

同文件重导不重复；同来源更新仅替换本来源，其他来源不变。导入器在写锁内重新生成映射、备份、逐条DDL与写入、外键/完整性/非判例表指纹校验，任何失败回滚。没有跳过备份的选项。

## 查询和页面行为

商品理解 → 原有宽召回＋判例双路检索 → 补充真实现行候选 → 规则查询 → 候选/判例事实比较 → 用户确认 → 终选与数据库核验。

- 文本检索跨税目；编码范围只辅助排序，不能阻断文本召回。两字中文LIKE补查；英文保留整词，避免偶然的两字母片段引入无关候选。
- 最多6条判例、6000字符。超预算的整例不进入提示词，也不能被引用。最多补20个现行编码，保留全部原候选，截断信息进入debug。
- 只有名称/描述文本匹配的判例可补充候选；税号范围匹配本身不能增码。同名、同税目和唯一前缀候选均不足以直接套用。
- LLM②/③比较相同事实、关键差异和缺失信息；普通流程仍3次逻辑调用。商品本质变化时额外重新理解/召回/终选，候选、规则、判例同时更新；空召回清空旧证据并拒答。
- `caseReferences` 只包含最终提示词实际给过的判例ID；原文和来源由数据库回填，模型只能提供独立标记的AI分析。现行税则优先，当前编码和数值仍由事实库校验。
- `caseKnowledgeStatus.status` 为 `disabled / unavailable / error / no_match / ready`。开关及知识版本参与缓存键。缺表或查询失败明确降级，不伪装成已检索成功。
- 结果页独立“参考判例”区，不替换“归类依据·税则原文”。支持、区别、不确定分别展示；原文折叠展开，缺失不补写，链接仅接受完整HTTP(S)，隐藏本机来源路径。旧历史记录不伪造判例；切到纯编码核验隐藏旧归类证据。

服务开关：`ruling.config.json` 控制默认值，环境变量 `HS_RULINGS=0|1` 优先；修改默认配置后需重启服务。`HS_DB_PATH` 指定测试数据库。回退优先使用 `HS_RULINGS=0`，不必删除判例或恢复整个事实库。

## 判例检索质量改进：主范畴特征匹配（2026-09-03）

上一节遗留的“收紧商品实质相关性”已落实。首轮对照暴露的两个病根——字面滑窗召回门槛过宽（017 塑料水壶召回玻璃淋浴房/尼古丁包/电池芯）、补码撒网污染候选池——通过“归类范畴特征匹配”修正。改进只收紧相关性，不改判例数据、真值标签或普通流程的三次调用。

### 做法

1. 离线为 104 条判例抽取归类特征，写入独立派生表 `ruling_case_feature`（category/sub_category/core_product/materials/function/structure/usage + 抽取模型/时间/源哈希）。脚本 `tools/extract-ruling-features.cjs`：幂等（源 sha256 未变则跳过）、改库前 `VACUUM INTO` 备份、单事务写入、通道降级、单条失败不中断。104 条全部由 `deepseek-v4-flash` 抽取成功。
2. LLM① 商品理解（`UNDERSTAND_SYSTEM`）增加 `category`/`sub_category` 输出，与判例共用同一套 17 类归类范畴枚举（`CATEGORY_LIST`，单一数据源置于 ruling-knowledge.js 并导出，抽取脚本与服务端同源）。
3. 判例检索从“字面滑窗 LIKE + heading 范围 + 多维文字打分”简化为**单一判断：商品与判例的归类主范畴相同才召回、才补码**（`sameCategory`，排除“其他”）。不做加权打分/材质因子/文字重合，查询逻辑简洁、可预测。
4. 无 `ruling_case_feature` 表时自动降级回原字面匹配（向后兼容旧库与全部原有测试）。

### 边界与待办

- **未重跑完整 80 流程对照**：以上为 3 例抽样端到端，不能替代两集×开关×20 的对照；是否将判例改为默认开启，须重跑对照按原安全门槛确认。判例当前仍默认关闭（`ruling.config.json` enabled=false）。
