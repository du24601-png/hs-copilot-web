# 真实商品冗长描述 20 例测试集

## 测试目标

这套测试只回答一个问题：**用户只输入一段冗长、带营销废话的真实商品描述时，系统最后建议的 10 位商品编码是否正确。**

不把候选池命中、提问质量、相似编码或 Top-3 算作正确。测试程序会调用 `/api/classify`，忽略系统生成的确认问题，再用空答案调用 `/api/decide`；只有 `selectedCode` 与标准答案完全相同才记 1 分。拒答、接口错误和只答对前 8 位都记 0 分。

## 答案从哪里来

1. 正确答案的前 8 位来自海关总署 2024 年、2025 年商品归类决定，不采用电商卖家自填编码。
2. 再用本项目 `hs_copilot.db` 的 2026 年库映射到 10 位；只选映射关系明确的案例。
3. Made-in-China、Alibaba、Walmart、厂商商城等页面仅用于证明商品确实在售，并补充真实营销话术、规格和包装噪声。
4. 每条数据都保存归类决定编号、决定来源和商品页面，便于人工复核。

## 数据结构和运行方法

- 数据集：`test/fixtures/real-products-noisy-20.json`
- 数据质量测试：`test/real-products-dataset.test.cjs`
- 在线回归程序：`tools/test-real-products-20.cjs`
- 默认结果：`tools/real-products-20-latest.json`

```powershell
npm test
npm run test:real20

# 只跑两个案例，或指定另一个服务地址
npm run test:real20 -- --only real-010,real-011
npm run test:real20 -- --base-url http://127.0.0.1:7100 --concurrency 2
```

## 解释结果时的边界

这是一个有意挑难、且经过筛选的 20 例回归集，适合发现语义理解、税则语言转换和候选召回问题；它不能代表所有真实业务的总体准确率。后续要估计真实准确率，仍需使用按业务分布抽样、由关务人员盲审的独立真值集。
