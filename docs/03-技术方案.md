# HS Copilot · 技术方案（简版）

> 2026-09-02 ｜ 对应代码：`hs-copilot-web/`

## 1. 总体架构

零构建、零框架依赖的轻量全栈：

```
浏览器（原生 HTML/CSS/JS 单页，4 个视图）
   │  fetch /api/*
   ▼
Node.js 原生 http 服务（server.js，无 Express）
   ├── SQLite（node:sqlite 内置驱动，只读）── hs_copilot.db
   └── LLM API（OpenAI 兼容 chat/completions，多通道降级）
```

- **无 npm 依赖**：Node ≥ 22（用内置 `node:sqlite`），`node server.js` 即启动；
- 数据库文件随项目自包含，整个目录拷走即可运行。

## 2. 目录结构

```
hs-copilot-web/
├── index.html        # 4 个视图（首页/确认/结论/申报）+ 归类路径浮层
├── styles.css        # 设计令牌 + 组件样式 + 进度/打字机动画
├── app.js            # 前端全部逻辑（路由、历史、动态渲染、动画）
├── server.js         # API + 静态文件服务 + 检索 + LLM 两阶段链路
├── llm.config.json   # 模型通道配置（含 API Key，勿外传/勿提交公开仓库）
└── hs_copilot.db     # SQLite 数据库（税则 + 申报要素 + CIQ 俗名 + 参考表 + FTS）
```

## 3. 数据层

- `hs_code`（12,032 行）：10 位编码、名称、品目注释、最惠国/增值税/出口/消费税率、监管条件字母；
- `declare_element`（114,284 行）：编码 → 申报要素（按 seq 排序）；
- `ciq_code`（24,074 行）：CIQ 俗名对照，用于口语化商品名命中；
- `hs_fts`：FTS5 全文索引；`hs_chapter` 及若干参考表（监管证件、国别、口岸等）。
- 数据来源：2026 年版进出口税则对照表（Excel 一次性导入）。

## 4. 候选检索（retrieveCandidates）

纯 SQL/JS 确定性打分，不经过大模型：

1. 中文分词段最长命中子串计分（防重复叠加）+ IDF 降权；
2. 品名结尾匹配加权、中心词（品名末 1~2 字）加权；
3. CIQ 俗名表辅助命中（带 IDF）；
4. 按品目（前 4 位）分组，最强组全量（≤12），其余组各取 2，共 ≤16 条候选；
5. 候选品目 <3 个时，调用一次大模型做查询扩展（quick 模式，失败不影响主流程）。

## 5. LLM 两阶段链路

| 阶段 | 接口 | 输入 | 输出 |
|---|---|---|---|
| P1 提问 | `POST /api/classify` | 商品描述 + 候选列表 | 商品名、已知属性、1~2 个确认问题（含选项/为什么问）、预选编码、拒答 |
| P2 定论 | `POST /api/decide` | 描述 + 已知属性 + 用户答案 + 候选列表 | 最终编码、置信度、3 条理由、反事实、备选、拒答 |

**安全钳制（sanitizePhase1/2）**：模型输出的编码必须命中候选集合，否则置空/拒答；名称、税率、要素等权威字段一律用编码回查数据库覆盖，**不使用模型返回的任何数值**。

**模型通道（llm.config.json，按序降级）**：
1. DeepSeek `deepseek-chat`（主通道，支持 `response_format: json_object`，实测 1~4s）；
2. OpenCode 免费模型（兜底，有按分钟限流，429 时等 12s 重试）；
3. 备用推理模型（最后兜底）。

每通道按 通道×模型 依次尝试；JSON 解析失败（含 think 标签、非 JSON 输出）自动切换下一个。P1 结果按查询串缓存 24h。

## 6. 前端要点

- 视图路由：`go(name)` 切换 4 个 section；
- 历史记录：localStorage（最近 50 条），classify 记录存完整 result 供重放；
- 确认页动态渲染：左卡属性（骨架屏→已知属性→待确认回填），右侧逐题 radio + 事件委托；
- 进度组件：分步定时推进，最后一步保持转圈直到接口返回；切后台时定时器被节流也不影响完成；
- 打字机：按墙上时钟计算应显字数（抗后台节流），`document.hidden` 时直接打满；用递增 token 作废切页前的旧任务；
- 申报页：要素清单来自当前编码的数据库记录，已知信息按规则预填（精确匹配→包含匹配，跳过"不确定"），行内编辑，一键复制。

## 7. 部署与运行

```bash
cd hs-copilot-web
node server.js        # 默认 http://127.0.0.1:7100/
```

目前为本地运行。上云时：整目录上传 + 进程守护（pm2/systemd）+ 反向代理即可；数据库只读，无需额外服务。

## 8. 已知限制与迭代方向

- 检索为词面匹配 → 计划引入向量语义检索；
- 提示词与拒答阈值需随 badcase 持续迭代；
- API Key 明文存于 `llm.config.json`，生产环境应改为环境变量/密钥管理；
- 单一窗口格式导出、图片/链接识别为预留未实现功能。
