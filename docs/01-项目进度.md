## 已知问题与边界

- **判例已入库，但不能直接套用**：104条有效性均未被确认；27条唯一候选也是前缀匹配，77条仍有多个候选，需业务复核。检索命中不等于适用，补充候选也可能增加终选干扰；
- **延迟约 15s**：3 次串行 LLM 调用 + 30~40 条候选的大 prompt；
- **模型非归类专家**：结论是"AI 预归类建议"，徽章固定提示"需人工复核"；
- **服务端非确定性**：temperature=0 下仍有轻微跑分波动；
- **API Key 明文**存于 `llm.config.json`（已 gitignore，勿提交公开仓库），生产应改环境变量/密钥管理；
- 历史记录存于浏览器本地，换浏览器/清缓存会丢失。
