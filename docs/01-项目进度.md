## 测试成绩

### A. 真实商品 20 例（海关归类决定真值集，多为疑难判例）

同一真值集、同一方法（classify → 忽略追问 → 空答案 decide → 精确匹配）：

| 模型 / 版本 | Final Correct | 备注 |
|---|---:|---|
| 旧版（中心词打分检索） | 2/20 | 召回低（Heading 12/20） |
| AI-native 简化 + deepseek-chat/glm | 5~6/20 | 召回高（Heading 19/20）但终选裁定口径缺失 |
| **v4-flash（关 thinking）** | **7/20** | 当前主通道；Refusal 0、单例约 15s |

失败主因：终选裁定口径缺失（"切碎即已磨""预烧即陶瓷"等个案判例未入库），而非召回。

### B. 出海电商 20 例（跨境电商常见消费品，模拟用户答题）

| 指标 | 成绩 |
|---|---:|
| Final Correct | **17/20（85%）** |
| Heading Recall / HS10 Recall | 20/20（100%） |
| Refusal / Error | 0 / 0 |
| 平均延迟 / P95 | ~10.8s / ~13.7s |

**核心结论**：系统对常见出海消费品表现好（85%、召回 100%），对海关疑难判例弱（35%）；两者瓶颈都在**终选细分**与**判例知识缺失**，而非召回。

## 已知问题与边界

- **归类决定判例证据仍缺**：GRI/类注/章注/本国子目注释已入库，但"切碎即已磨""预烧即陶瓷"等个案裁定口径尚未建立证据层（真实集准确率天花板）；
- **延迟约 15s**：3 次串行 LLM 调用 + 30~40 条候选的大 prompt；
- **模型非归类专家**：结论是"AI 预归类建议"，徽章固定提示"需人工复核"；
- **服务端非确定性**：temperature=0 下仍有轻微跑分波动；
- **API Key 明文**存于 `llm.config.json`（已 gitignore，勿提交公开仓库），生产应改环境变量/密钥管理；
- 历史记录存于浏览器本地，换浏览器/清缓存会丢失。
