# HS Copilot 部署清单（腾讯云轻量 + Ubuntu）

> 历史方案。当前阿里云 + GitHub 部署以 [GITHUB-DEPLOY.md](GITHUB-DEPLOY.md) 为准。
> 当前 Nginx 方案让应用监听 `127.0.0.1:7100`，不需要将应用端口暴露到公网。

> 针对 `hs-copilot-web` 定制。结论先说：这个项目**零 npm 依赖、数据库只读**，
> 是部署友好度最高的一类，服务器上不需要 `npm install`，更新数据库前仍需保留数据副本。

## 你的项目部署画像（已实测确认）

| 项目 | 实况 | 对部署的影响 |
|---|---|---|
| 依赖 | 零 npm 包，纯 Node 内置模块 | 不用 `npm install`，部署快 |
| 数据库 | `hs_copilot.db` 24MB，**只读打开** | 运行期不修改数据库，更新前保留数据副本 |
| Node 版本 | 本地开发用 v24.13.0 | 服务器装 **Node 24**（不要装 22） |
| 监听地址 | 默认 `127.0.0.1` | 使用 `HOST=127.0.0.1`，由 Nginx 对外转发 |
| 大模型 | DeepSeek，国内服务器直连 | 不需要代理 |
| 静态资源 | 6 个文件，已做白名单加固 | 加新前端文件要登记白名单（见文末） |

## 第一步：买服务器

腾讯云轻量应用服务器，**2核2G / 4M带宽 / 50G SSD / 300G月流量，¥99/年**（约 ¥8/月）。
新用户秒杀区有 **¥38/年 的 4核4G**，能抢到就抢。

- 镜像选 **Ubuntu 24.04 LTS**
- 地域选离你近的（上海 / 北京 / 广州）
- 买 1 年，别买 3 年（MVP 可能两个月就转型）

> 备用：阿里云轻量同档位，价格接近。

---

## 第二步：连上服务器

在腾讯云控制台拿到**公网 IP** 和 **root 密码**（轻量服务器默认 root 登录）。

本机打开 Git Bash 或 PowerShell：

```bash
ssh root@你的公网IP
```

首次登录会问 `Are you sure you want to continue?`，输 `yes`。

---

## 第三步：装环境（复制粘贴执行）

```bash
# 1. 更新系统
apt update && apt upgrade -y

# 2. 装 Node 24（NodeSource 源）
curl -fsSL https://deb.nodesource.com/setup_24.x | bash -
apt install -y nodejs

# 3. 验证版本，应显示 v24.x
node -v

# 4. 验证 node:sqlite 可用（本项目核心依赖）
node -e "require('node:sqlite'); console.log('sqlite OK')"
# 会出现一行 ExperimentalWarning 警告，不用担心，属正常

# 5. 装 pm2（进程守护，挂了自动重启）
npm install -g pm2

# 6. 装 Nginx（对外门户 + HTTPS）
apt install -y nginx
```

---

## 第四步：上传代码

**在本机**（不是服务器）打开 Git Bash，进项目目录：

```bash
cd /d/hs-copilot-web

# 打包（排除 .git 和缓存，约 25MB）
tar --exclude=.git --exclude=.workbuddy --exclude=__pycache__ \
    --exclude='*.db-shm' --exclude='*.db-wal' \
    -czf hs-copilot.tar.gz .

# 上传到服务器
scp hs-copilot.tar.gz root@你的公网IP:/root/
```

**回到服务器**：

```bash
mkdir -p /opt/hs-copilot
cd /opt/hs-copilot
tar -xzf /root/hs-copilot.tar.gz
ls   # 应看到 server.js、index.html、hs_copilot.db、deploy/ 等
```

---

## 第五步：放密钥

把你本机的 `llm.config.json` 上传到服务器（它已被 .gitignore 忽略，不会进 git）：

```bash
# 在本机执行
scp /d/hs-copilot-web/llm.config.json root@你的公网IP:/opt/hs-copilot/
```

**在服务器上锁死权限**，只允许 root 读：

```bash
chmod 600 /opt/hs-copilot/llm.config.json
```

> 为什么可以放心放：静态目录已加固，`/llm.config.json` 不会被 HTTP 返回（已实测 403）。
> 如果哪天想彻底不落盘，改用环境变量 `LLM_API_KEY` + `LLM_BASE_URL` 也支持，
> 但那样会丢失配置里第二个 provider（opencode 免费模型）。

---

## 第六步：启动服务

用同目录下的 `ecosystem.config.cjs`（pm2 配置，已准备好）：

```bash
cd /opt/hs-copilot
mkdir -p /var/log/hs-copilot
pm2 start deploy/ecosystem.config.cjs
pm2 save
pm2 startup    # 按它输出的提示再执行一行命令，实现开机自启
```

验证服务活着：

```bash
curl http://127.0.0.1:7100/api/health
```

应看到：`{"ok":true,"db":true,"llm":true,...}`

- `db:false` → 没找到 `hs_copilot.db`，检查文件在不在 `/opt/hs-copilot/`
- `llm:false` → 密钥没读到，检查 `llm.config.json`

---

## 第七步：配 Nginx 对外

把 `deploy/nginx-hs-copilot.conf` 复制到服务器，改掉里面的 `server_name`：

```bash
# 编辑配置，把 你的域名或IP 换成实际 IP
nano /etc/nginx/sites-available/hs-copilot
# (粘贴 deploy/nginx-hs-copilot.conf 的内容)

ln -s /etc/nginx/sites-available/hs-copilot /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t          # 必须显示 syntax is ok
systemctl reload nginx
```

> 配置里 `proxy_read_timeout 180s` 是**关键**：大模型一次调用可能要几十秒，
> Nginx 默认 60 秒就掐断，会表现为"点了没反应"。

---

## 第八步：开防火墙

```bash
ufw allow 22
ufw allow 80
ufw allow 443
ufw enable
```

**同时去腾讯云控制台 → 防火墙（安全组）**，放行 80 和 443 端口。
轻量服务器有独立于系统的安全组，两边都要开，只开一边会连不上。

> 注意：**不要**放行 7100。外网只允许走 Nginx 的 80/443。

---

## 第九步：验证

浏览器打开 `http://你的公网IP/`，应该看到 HS Copilot 页面。
输入一个商品试试完整链路（会真实调用 DeepSeek）。

---

## 关于域名和备案（重要）

- **阶段一（推荐先这样）**：直接用 IP 访问，不需要备案，今天就能用。
- **阶段二**：买域名 → 解析到 IP → **必须 ICP 备案**（10–20 天）。
  国内服务器 + 域名，没备案会被拦在 80 端口，访问不了。
- 备案完成后才能申请 HTTPS 证书：

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名
certbot renew --dry-run   # 验证自动续期
```

## 维护提醒：加前端文件要登记白名单

`server.js` 里有一段静态资源白名单（约 933 行）：

```js
const STATIC_ALLOW = new Set([
  '/index.html', '/styles.css',
  '/app.js', '/confirm-logic.js', '/decision-logic.js', '/ruling-view.js',
  '/favicon.ico'
]);
```

以后新增前端 css / js / 图片，必须把路径加进这个集合，
否则线上会返回 403（本地测试也一样，所以本地就能发现）。
这是为了挡住密钥和源码泄露，故意设的门槛。
